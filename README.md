# 📞 DutyCall · 值班助手

> 一款专为 IT 运维、值班班组设计的智能呼叫转移自动化工具。告别每天手动按 `**21*号码#` 的繁琐，让排班与电话转移一步到位。

在日常运维工作中，值班手机的无条件呼叫转移往往需要每天手动设置。尤其在人员轮换频繁、班组人数不固定的情况下，不仅操作繁琐，且极易出错。**DutyCall** 致力于将"排班日历"与"系统拨号"打通，实现一键智能切换。

- **转移结果判断**：以前只要运营商回了内容就算成功，回执里写"设置失败"也照记不误。现在会解析回执文案，区分**成功 / 失败 / 待确认**三种结果：

  - 回执照样看不懂（或走兼容模式拨号）→ 显示「已发起转移，待确认」，不再假装成功；
  - 运营商回执原文同时记进 `last_response`，排查问题时可直接查看。
- **单选组选不中**：「从谁开始」「临时换人」弹窗里第一个选项的 id 为 0，等同于 `View.NO_ID`，导致只有一个人时点确定毫无反应。

## 🧮 进阶：自定义排班公式完全指南

在规则向导中选择"新建自定义公式"或"选择已保存的公式"，你可以像写代码一样定义轮班。系统内置了强大的表达式解析引擎（基于 EvalEx），并在保存时进行语法校验。

### 1. 核心运行机制

公式的最终目的，是**计算出一个整数**。

- 如果算出 `1`，系统就安排第 1 个人（M1）值班。
- 如果算出 `3`，系统就安排第 3 个人（M3）值班。
- **安全保护**：如果算出的结果越界（比如算出 `0` 或 `8`，但实际只有 5 个人），引擎会自动通过取余将其安全映射到有效范围内。

### 2. 可用变量字典 (Variables)

| 变量名 | 含义 | 示例说明 |
| :--- | :--- | :--- |
| **`N`** | 当前总人数 | 如果人员列表有 5 个人，`N = 5`。 |
| **`d`** | 天数偏移量 | 从起始日算起，今天=`0`，明天=`1`，昨天=`-1`。 |
| **`w`** | 周数偏移量 | 从起始日算起，本周=`0`，下周=`1`，上周=`-1`。 |
| **`m`** | 月数偏移量 | 从起始日算起，本月=`0`，下月=`1`，上月=`-1`。 |
| **`dow`** | 星期几 (Day of Week) | 周一=`1`，周二=`2` …… 周六=`6`，周日=`7`。 |
| **`dom`** | 当月第几天 (Day of Month) | 每月 1 号=`1`，每月 15 号=`15`。 |

> 设置页的「排班进度微调」会把偏移量叠加到 `d` / `w` / `m` 上。如果公式里压根没用到某个变量，调整对应偏移量自然看不到变化——这是正常现象。

### 3. 可用函数与运算符 (Functions & Operators)

- **数学运算**：`+` (加)、`-` (减)、`*` (乘)、`/` (除)。
- **比较运算**：`==` (等于)、`>` (大于)、`<` (小于)、`>=` (大于等于)、`<=` (小于等于)。
- **逻辑运算**：`&&` (且)、`||` (或)。
- **核心函数 `mod(a, b)`**：求余数。保证结果永远为正数（如 `mod(-1, 5)` 会得到 `4`），是轮转排班的核心。
- **核心函数 `if(条件, 结果A, 结果B)`**：条件判断。如果条件成立，返回结果A；否则返回结果B。

### 4. 实战配方（从基础到进阶）

#### 💡 基础篇：从最简单的开始

**需求**：无论多少个人，按名单顺序，每天换一个人。
**公式**：`mod(d, N) + 1`
*(解释：过了多少天对总人数取余，加上 1 是因为序号从 1 开始)*

**需求**：按周轮换，一人值一周。
**公式**：`mod(w, N) + 1`
*(解释：只看过了多少周，同周内的每一天算出来的人都是同一个)*

#### 💡 进阶篇：条件分支与特殊处理

**需求**：工作日（周一至周五）按天轮换，但周末（周六日）固定由第 1 个人值班。
**公式**：`if(dow >= 6, 1, mod(d, N) + 1)`
*(解释：如果今天是周六(6)或周日(7)，直接返回 1；否则执行正常的按天轮换)*

**需求**：平时按周轮换，但每逢每个月 1 号，固定由第 1 个人值班（打报表专用）。
**公式**：`if(dom == 1, 1, mod(w, N) + 1)`
*(解释：如果今天是当月第 1 天，强行返回 1；否则按周轮换)*

**需求**：工作日 5 个人轮（M1-M5），周末 2 个人单独轮（M6、M7）。
**公式**：`if(dow >= 6, mod(w, 2) + 6, mod(d, 5) + 1)`
*(解释：周末用周数对 2 取余，结果加 6 得到 M6 或 M7；工作日用天数对 5 取余，结果加 1 得到 M1 到 M5)*

### 5. 把公式沉淀下来

写好的公式可以在「规则向导 → 新建自定义公式」里填一个备注再保存，它会自动进入公式库；也可以到「设置 → 高级 → 公式管理」里单独维护。

排班页点击「点击查看 / 编辑当前公式」可以：

- **单击**公式文本框 → 直接修改，改完点「保存」生效（保存前同样会做语法校验）。
- **双击** → 复制到剪贴板。
- **更换** → 从公式库另选一条替换当前公式。

### 6. ⭐ 复杂规则：让 AI 帮你写公式

如果你想出了极其复杂的规则，但不知道怎么写成公式，可以直接把下面这段**提示词（Prompt）**连同你的需求发给 Deepseek / ChatGPT / Claude / 文心一言 等 AI：

> 你是一个排班算法专家。请帮我根据以下需求生成一段排班表达式。
>
> 【可用变量】
> N: 总人数; d: 偏移天数; w: 偏移周数; m: 偏移月数; dow: 星期几(1-7); dom: 当月几号(1-31)。
>
> 【可用函数】
> mod(A, B): 取模（结果恒为非负整数）
> if(条件, 真值, 假值): 条件判断
>
> 【我的需求】：
> （在这里用大白话描述你的规则。）
>
> 请只输出最终公式，不要解释。

## 🔄 后台自动转移说明

设置页开启「自动执行」后：

1. 每天到达设定时间，App 会在后台自动把呼叫转移切换到当日值班人，不弹拨号盘、不亮屏。
2. 若当时手机处于深度待机导致定时被延后，解锁手机会自动补执行一次；同一天只会执行一次。
3. 通知栏常驻显示「今日值班 · 当前转移状态」，可直接从通知或悬浮图标回到 App。
4. 悬浮图标可拖动，位置会被记住；贴边待命时会自动变淡，拖动时恢复清晰。

需要注意：

- 只有「静默注册」支持后台执行。「兼容模式」走系统拨号，系统不允许非默认拨号器在后台拨出转移指令，因此后台自动转移不会生效。
- 「静默注册」全程没有可见界面，前台手动点击也不会弹出任何提示；「兼容模式」会弹出一张「来电转移已注册」的系统提示，这是系统行为，无法屏蔽。
- 部分国产系统（魅族 Flyme、华为 EMUI 等）会在熄屏后冻结后台进程，此时定时广播会被系统直接丢弃，表现为"到点没执行"。遇到这种情况需要把本应用加入系统的「允许后台运行 / 自启动」白名单并关闭电池优化。实测在魅族 22（Android 16）上，即使使用最严格的 alarm clock 闹钟，未加白名单仍会被冻结拦截。
- 兜底机制：打开 App 的瞬间会自动补执行当天漏掉的自动转移，因此即使定时被拦，用户解锁并打开 App 后仍会完成切换。
- 「解锁时立即执行」：开启无障碍服务后，系统会持续绑定本应用，值班人解锁手机时立即检查并完成当天转移。实测在魅族 22（Android 16）上，机器熄屏 4 分钟期间进程未被冻结，解锁后几秒内完成静默切换，全程不需要打开 App。该服务不读取屏幕内容，只消费系统的解锁/窗口切换事件。
- 建议在系统设置中为本应用开启：通知权限、悬浮窗权限、「闹钟和提醒」权限、以及允许后台运行/忽略电池优化。荣耀/华为机型还需在「应用启动管理」中允许自启动。

## 🛠️ 编译与运行

如果你想自己编译代码：

```bash
git clone https://github.com/ExEafnv/DutyCall.git
cd DutyCall
./gradlew assembleRelease
```

环境要求：Android Studio（AGP 9.3.x / Gradle 9.5）、JDK 17 及以上（源码按 Java 11 编译）、minSdk 29（Android 10）。

首次打开请授予 App「拨打电话」权限。若希望后台自动转移生效，还需要授予「通知」「悬浮窗」「闹钟和提醒」权限；想要解锁补偿则需手动开启无障碍服务。
