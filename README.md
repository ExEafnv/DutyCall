# 📞 DutyCall · 值班助手

> 一款专为 IT 运维、值班班组设计的智能呼叫转移自动化工具。告别每天手动按 `**21*号码#` 的繁琐，让排班与电话转移一步到位。

在日常运维工作中，值班手机的无条件呼叫转移往往需要每天手动设置。尤其在人员轮换频繁、班组人数不固定的情况下，不仅操作繁琐，且极易出错。**DutyCall** 致力于将“排班日历”与“系统拨号”打通，实现一键智能切换。

## 🧮 进阶：自定义排班公式完全指南

在规则向导中选择“自定义公式”模式，你可以像写代码一样定义轮班。系统内置了强大的表达式解析引擎（基于 EvalEx），并在输入时进行实时语法校验。

### 1. 核心运行机制
公式的最终目的，是**计算出一个整数**。
- 如果算出 `1`，系统就安排第 1 个人（M1）值班。
- 如果算出 `3`，系统就安排第 3 个人（M3）值班。
- **安全保护**：如果算出的结果越界（比如算出 `0` 或 `8`，但实际只有 5 个人），引擎会自动通过取余将其安全映射到有效范围内。

### 2. 可用变量字典 (Variables)

| 变量名 | 含义 | 示例说明 |
| :--- | :--- | :--- |
| **`N`** | 当前总人数 | 如果人员列表有 5 个人，`N = 5`。 |
| **`d`** | 天数偏移量 | 从起始日算起，今天=`0`，明天=`1`，昨天=`-1`。 |
| **`w`** | 周数偏移量 | 从起始日算起，本周=`0`，下周=`1`，上周=`-1`。 |
| **`m`** | 月数偏移量 | 从起始日算起，本月=`0`，下月=`1`，上月=`-1`。 |
| **`dow`** | 星期几 (Day of Week)| 周一=`1`，周二=`2` …… 周六=`6`，周日=`7`。 |
| **`dom`** | 当月第几天 (Day of Month)| 每月 1 号=`1`，每月 15 号=`15`。 |

### 3. 可用函数与运算符 (Functions & Operators)

- **数学运算**：`+` (加)、`-` (减)、`*` (乘)、`/` (除)。
- **比较运算**：`==` (等于)、`>` (大于)、`<` (小于)、`>=` (大于等于)、`<=` (小于等于)。
- **逻辑运算**：`&&` (且)、`||` (或)。
- **核心函数 `mod(a, b)`**：求余数。保证结果永远为正数（如 `mod(-1, 5)` 会得到 `4`），是轮转排班的核心。
- **核心函数 `if(条件, 结果A, 结果B)`**：条件判断。如果条件成立，返回结果A；否则返回结果B。

### 4. 实战配方（从基础到进阶）

#### 💡 基础篇：从最简单的开始
**需求**：无论多少个人，按名单顺序，每天换一个人。
**公式**：`mod(d, N) + 1`
*(解释：过了多少天对总人数取余，加上 1 是因为序号从 1 开始)*

**需求**：按周轮换，一人值一周。
**公式**：`mod(w, N) + 1`
*(解释：只看过了多少周，同周内的每一天算出来的人都是同一个)*

#### 💡 进阶篇：条件分支与特殊处理
**需求**：工作日（周一至周五）按天轮换，但周末（周六日）固定由第 1 个人值班。
**公式**：`if(dow >= 6, 1, mod(d, N) + 1)`
*(解释：如果今天是周六(6)或周日(7)，直接返回 1；否则执行正常的按天轮换)*

**需求**：平时按周轮换，但每逢每个月 1 号，固定由第 1 个人值班（打报表专用）。
**公式**：`if(dom == 1, 1, mod(w, N) + 1)`
*(解释：如果今天是当月第 1 天，强行返回 1；否则按周轮换)*

**需求**：工作日 5 个人轮（M1-M5），周末 2 个人单独轮（M6、M7）。
**公式**：`if(dow >= 6, mod(w, 2) + 6, mod(d, 5) + 1)`
*(解释：周末用周数对 2 取余，结果加 6 得到 M6 或 M7；工作日用天数对 5 取余，结果加 1 得到 M1 到 M5)*

### 5. ⭐ 复杂规则：让 AI 帮你写公式

如果你想出了极其复杂的规则，但不知道怎么写成公式，可以直接把下面这段**提示词（Prompt）**连同你的需求发给 Deepseek / ChatGPT / Claude / 文心一言 等AI：

> 你是一个排班算法专家。请帮我根据以下需求生成一段排班表达式。
> 
> 【可用变量】
> N: 总人数; d: 偏移天数; w: 偏移周数; m: 偏移月数; dow: 星期几(1-7); dom: 当月几号(1-31)。
> 
> 【可用函数】
> mod(A, B): 取模（结果恒为非负整数）
> if(条件, 真值, 假值): 条件判断
> 
> 【我的需求】：
> （在这里用大白话描述你的规则。）
> 
> 请只输出最终公式，不要解释。

## 🛠️ 编译与运行

如果你想自己编译代码：

```bash
git clone https://github.com/ExEafnv/DutyCall.git
cd DutyCall
./gradlew assembleRelease
```

注意：首次打开请授予 App “拨打电话”的权限。由于 Android 系统的安全限制，App 在后台定时自动拨号无法做到绝对静默（这是防诈骗机制），目前发布版主要依赖前台一键点击转移。
